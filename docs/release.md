# Alpha 发布检查

此目录是独立源码仓库的根目录。公开源码不等于正式发布兼容所有设备的安装包；以下检查用于后续打包发布。

## 当前边界

- `0.2–0.2.11` 的实机结果记录在兼容性文档中。
- `0.3.0-alpha.3` 在原有通信认证、设备配置和构建流程上合入长按、息屏、界面恢复、可选配对精调、输出路由和 TV-Mute 修复，仍需实机回归。
- 新版不能宣称已解决重启后的 ADB 开关或长期稳定性问题。
- 默认构建生成的是本地 debug 签名 APK，现阶段以分享源码、供开发者复现为主。

已完成的构建与离线检查见[本地验证记录](validation.md)。

## 发布安装包前

- [ ] 确定用于后续版本升级的签名密钥并单独备份；不要提交到 Git。
- [ ] 在目标电视完成全新安装、首次 ADB 授权、退出及重新启动。
- [ ] 用 AirPods 和电视扬声器分别确认实际响度、音量条和长按行为。
- [ ] 用公开脚本完成自己的 PIN 配对、私有配置安装、替换与撤销，不复用开发者凭据。
- [ ] 验证标准/超细步进、路由过期/未知/混合、网络中断和不确定写入不二次执行。
- [ ] 验证进入转发界面和断开耳机后的电视扬声器恢复、完整耳机切换，以及静音/零音量时的 HDMI TV-Mute 同步。
- [ ] 验证方向、确认、返回、主页键及手动直控模式。
- [ ] 切换其他 HDMI 后返回，验证自动恢复。
- [ ] 电视真正重启，按文档手动开启 ADB 后验证恢复。
- [ ] 验证 `stop` 后后台不再自动打开应用，以及完整 `uninstall`。
- [ ] 验证三个联动开关分别关闭、双向无回送，以及首页小窗/全屏恢复。
- [ ] 验证异常中断后恢复临时设备自动关机设置；评估 CEC 广播对其他 HDMI 设备的影响。
- [ ] 发布说明保留“实验性、仅单台设备旧版实测、新版测试范围”的准确表述。

## 准备提交

只提交此目录中的源码、脚本、文档和许可证。`.gitignore` 排除了默认构建目录、
APK/JAR、配对配置、签名文件和常见本机调试文件；不要使用 `git add -f` 绕过这些保护。
提交时先检查 `git diff --cached --stat` 和暂存内容，再推送。

公开问题反馈不需要网络地址、账号、ADB 授权密钥或原始家庭照片。
