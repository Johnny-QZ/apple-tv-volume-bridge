# Apple TV 音量转发

让小米电视遥控器控制 Apple TV 所连接的 AirPods 音量，支持更细的音量调节，并让电视息屏、亮屏与 Apple TV 休眠、唤醒联动。

这个项目来自日常使用中的三个困扰。我带着这些问题，尝试借助 GPT 分析原因、编写程序，再在自己的设备上反复验证，逐步做出了对应的解决办法。

| 遇到的问题 | 对应的解决办法 |
| --- | --- |
| **电视遥控器无法控制 AirPods 音量。** 借助 HDMI-CEC，电视遥控器的方向键、确认键和返回键已经能正常操作 Apple TV，但音量键仍然只控制电视本身。使用连接在 Apple TV 上的 AirPods 时，想调耳机音量，还得换用 Apple TV 遥控器。 | **补上音量键控制。** 将电视遥控器的音量加减传给 Apple TV，调节连接在 Apple TV 上的 AirPods 音量。 |
| **电视息屏与 Apple TV 休眠无法联动。** 电视电源键可以设置为“关机”或“息屏”。在我这台电视上，原有的 HDMI-CEC 开关机联动只在“关机”模式下生效，无法用于息屏。而音量转发软件需要保持 ADB 调试开启：真正重启电视后需要重新打开 ADB，息屏后再唤醒则能保留开启状态，因此也希望让息屏参与联动。 | **加入息屏与唤醒联动。** 电视息屏时让 Apple TV 休眠；Apple TV 唤醒或休眠时，让电视随之亮屏或息屏。这三项可分别开启，公开版默认关闭。 |
| **AirPods 每格音量跨度太大。** 在 Apple TV 上调节 AirPods 音量，经常遇到加一格太响、减一格又太轻，很难调到合适的音量。 | **加入耳机音量精调。** 完成配对和耳机识别配置后，提供原有实测步长约 `1/3`、`1/6` 的两档调节幅度，让音量更容易调到合适的大小。 |

实测设备为**小米大师 82** 和 Apple TV `A2169`。上述功能已在自用原型 `0.2.11` 上逐步验证；当前公开源码 **`0.3.0-alpha.4` 通过了离线构建和测试，尚未实机回归**，不保证其他设备直接可用。
