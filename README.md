# Apple TV 音量转发

让原装小米电视遥控器也能调节 Apple TV 所连接的 AirPods 音量。看电视时，不用为了调耳机音量再换一只遥控器。

起因是一个很直观的疑问：电视遥控器的方向键、确认键都能操作 Apple TV，为什么音量键却只调电视本身？能不能把缺少的这两个按键补上？

于是尝试借助 GPT 阅读日志、分析代码、编写和修改程序，逐步发现：在这台电视上，原厂播放器会过滤音量加减，简单补键并不能奏效。最后走通的办法，是在更早的位置接住遥控器按键，再把音量操作交给 Apple TV。GPT 协助探索与实现，我则在自己的设备上反复操作和对照验证：实际有没有声音、长按是否正常，再根据反馈继续修改。

随后又围绕日常使用，逐项处理了这些问题：

- **确认键长按会提前结束**：在支持长按二倍速的视频软件里，让操作持续到松手。
- **切走再回来需要重新打开**：返回 Apple TV 信号源时自动恢复转发。
- **进入画面或断开耳机后，电视可能无声**：恢复电视扬声器声音，同时尊重原有的静音和零音量设置。
- **想关屏，又不想每次重新开调试**：使用电视原生息屏，并加入可选的休眠、唤醒联动；唤醒时保留首页小窗或恢复全屏。
- **耳机一格音量太大**：提供已测单步的 `1/3`、`1/6` 精调。完成配对并认出自己的耳机后使用细步进，其他输出或状态不明时自动回到默认音量控制。

已使用的设备是**小米大师 82** 和 Apple TV `A2169`。私有原型 `0.2.11` 已在这套设备上实测；当前公开源码 **`0.3.0-alpha.4` 只完成离线构建和测试，尚未实机回归**。它是针对个人设备做的实验，不保证其他电视、耳机或系统版本直接可用。公开版息屏联动默认关闭；真正重启或断电后，测试电视仍需要手动重新开启 ADB 调试并打开应用。
