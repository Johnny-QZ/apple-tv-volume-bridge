# Apple TV 音量转发

让小米电视遥控器控制 Apple TV 所连接的 AirPods 音量，支持更细的音量调节，并让电视息屏、亮屏与 Apple TV 休眠、唤醒联动。

这个项目来自日常使用中的三个困扰。我带着这些问题，尝试借助 GPT 分析原因、编写程序，再在自己的设备上反复验证，逐步做出了对应的解决办法。

| 遇到的问题 | 对应的解决办法 |
| --- | --- |
| **电视遥控器调不到 AirPods 音量。** 方向键、确认键已经能操作 Apple TV，音量键却只调电视本身，听耳机时还得换一只遥控器。 | **补上音量键控制。** 将电视遥控器的音量加减传给 Apple TV，调节连接在 Apple TV 上的 AirPods 音量。 |
| **电视息屏与 Apple TV 休眠无法联动。** 想保留电视的运行状态、只关闭屏幕，原有的开关机联动却无法满足这个需求。 | **加入息屏与唤醒联动。** 电视息屏时让 Apple TV 休眠；Apple TV 唤醒或休眠时，让电视随之亮屏或息屏。这三项可分别开启，公开版默认关闭。 |
| **AirPods 每格音量跨度太大。** 在 Apple TV 上调音量，有时加一格太响、减一格又太轻，很难找到合适的位置。 | **加入耳机音量精调。** 完成配对和耳机识别配置后，提供原有实测步长约 `1/3`、`1/6` 的两档调节幅度，让音量更容易调到合适的大小。 |

实测设备为**小米大师 82** 和 Apple TV `A2169`。上述功能已在自用原型 `0.2.11` 上逐步验证；当前公开源码 **`0.3.0-alpha.4` 通过了离线构建和测试，尚未实机回归**，不保证其他设备直接可用。
